# Репликация сравнения 1,2 и 2 млн пользователей

## Итог

На фиксированной июльской выборке из 100 тыс. пользователей модель, обученная на всех доступных данных (1 985 972 пользователя, в тексте округлено до 2 млн), превысила вариант на 1,2 млн при всех трёх инициализациях модели. Для каждой инициализации парный 95% интервал разности Recall@5 и NDCG@5 лежит выше нуля.

Средний прирост по трём инициализациям составил 0,00294 Recall@5 и 0,00248 NDCG@5. Это описательные средние: трёх инициализаций недостаточно для надёжного межинициализационного доверительного интервала.

## Условия сравнения

- Вспомогательная модель: `d_model=64`, два профиля интересов.
- Пользователи для обучения отбирались одним вложенным порядком с `subset_seed=42`.
- Инициализации модели: 42, 7 и 123.
- Эпоха выбиралась по одной июньской выборке из 20 тыс. пользователей.
- Итоговые метрики считались на одной июльской выборке из 100 тыс. пользователей.
- Для каждого seed сравнение 1,2 и 2 млн выполнено по тем же пользователям; использован парный bootstrap с 20 тыс. повторов.
- Аудит подтвердил одинаковый порядок псевдонимизированных идентификаторов и одинаковые метки во всех шести прогнозах. Исходных `user_id` в прогнозах нет.
